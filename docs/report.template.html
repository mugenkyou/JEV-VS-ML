Descriptive Summary

Raw zero-shot Jev leads the best classical pipeline mean on IMDb and SMS Spam. The largest advantage is IMDb: +7.9 percentage points. Across tabular datasets, classical tree and kernel models maintain an empirical lead.

02 / Analysis

Key Benchmark Findings

A nuanced breakdown of performance across domain types, decision rules, and few-shot conditioning.

Finding 01 · Text Sentiment

Sentiment polarity is the strongest differentiator.

On IMDb, zero-shot Jev reaches 96.3% balanced accuracy, compared with 88.4% for TF-IDF Logistic Regression. The +7.9-point advantage persists after policy calibration (96.1% vs. 88.3%). This reflects strong natural language understanding on long-form sentiment review tasks.

Finding 02 · Threshold Calibration

Policy threshold tuning alters the SMS Spam outcome.

Under raw decision rules, zero-shot Jev leads Naive Bayes (96.1% vs. 95.0%). However, once decision thresholds are calibrated on the policy split, Naive Bayes reaches 96.3% against Jev’s 95.9%. Threshold selection is critical on imbalanced binary tasks.

Finding 03 · Tabular Complexity

Structured tabular business tasks favor classical pipelines.

On Bank Marketing, adjusted zero-shot Jev scores 59.7% vs. 73.3% for the voting ensemble. On Online Shoppers, few-shot Jev reaches 53.6% vs. 71.2%. Standard feature transformers and tree ensembles remain substantially more effective on numerical business attributes.

Finding 04 · Few-Shot Conditioning

In-context training examples help selectively.

Providing one example per class lifts raw Breast Cancer from 61.0% to 88.8% and Banking77 from 78.9% to 81.9%. Conversely, few-shot conditioning slightly reduces mean scores on AG News and IMDb. Task structure determines few-shot efficacy.

03 / Experimental Protocol

Methodology & Pipeline Design

Protocol 3.0.1 strictly isolates candidate selection, policy threshold calibration, and test evaluation.

01 · Holdout Split

Fixed Test Holdout

Dedicated test set created before any model exploration (Seed 20260920). Remains completely isolated from feature fitting and tuning.

02 · Train / Val / Policy

Partition Budgets

Up to 8,000 training rows, 1,000 validation rows for hyperparameter selection, and 500 labeled policy rows for threshold calibration.

03 · Feature Pipelines

Transform-Only Flow

TF-IDF vocabulary and standard scalers are fitted strictly on the training partition and applied statelessly to subsequent splits.

04 · GPU Subprocess

Isolated Execution

Subprocess GPU execution with explicit CUDA device masking, preflight compatibility verification, and isolated memory cleanup.

06 / Scope & Limitations

Limitations & Analytical Boundaries

Explicit documentation of boundary conditions, statistical assumptions, and non-claims.

Statistical Inference

Reported ± values represent sample standard deviations across 3 random training seeds on the same test set. They do not constitute formal confidence intervals or hypothesis tests.

Cached Zero-Shot Calls

Identical successful API requests are cached and reused across seeds. Zero variance on zero-shot Jev rows reflects deterministic prompt caching rather than independent API replications.

Banking77 API Failures

Requests yielding unparseable or out-of-vocabulary label predictions were assigned failure code -1 and counted as incorrect. Scores include API formatting compliance factors.

Sample Size Constraints

Iris (n=30) and Breast Cancer (n=114) feature compact holdout sets. Near-perfect scores on these small samples should not be generalized to larger real-world distributions.

Classical Baseline Scope

Classical pipelines operate under a strict computational budget (max 150 trees, 60 hist iterations, 4 tuning candidates). They do not represent fine-tuned deep neural transformers.

Latency & Cost Scope

The benchmark logged 38,922 request attempts with an estimated ~$4.19 input cost. This is an empirical run estimate and should not be treated as a production SLA or billing quote.
